## Descripción del Proyecto:

Aplicación web desarrollada con Next.js para gestionar el inventario de un restaurante por neveras o categorías. Permite controlar productos, cantidades y detectar stock bajo o agotado. Incluye dashboard interactivo, listas de compra y sistema de roles para gestionar accesos.
